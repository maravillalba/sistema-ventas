# Sistema de Ventas de Indumentaria

Sistema destinado a la gestión de ventas de un comercio de indumentaria.

## Objetivo

El proyecto busca brindar una solución para gestionar productos, clientes y ventas de manera organizada.

## Estructura del proyecto

* `backend/`: código correspondiente al backend del sistema.
* `database/`: scripts y archivos relacionados con la base de datos.
* `docs/`: documentación del proyecto.
* `tests/`: pruebas del sistema.
