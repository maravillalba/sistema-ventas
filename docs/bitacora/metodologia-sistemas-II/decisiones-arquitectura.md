### 07/09/2026 — Definición del nombre y alcance del sistema

Se definió como nombre oficial del proyecto **Sistema de Gestión de Ventas**.

El sistema se desarrolla dentro del dominio de **venta de indumentaria**, pero el término "indumentaria" no forma parte del nombre del sistema. Esta decisión permite mantener una denominación clara y flexible, evitando limitar el sistema únicamente a un tipo específico de indumentaria.

A partir de esta decisión, se utilizará de manera consistente el nombre **Sistema de Gestión de Ventas** en la documentación, repositorio, trabajos prácticos y futuras etapas de desarrollo.
